# 后续计划

## 阶段 0：项目骨架

状态：已完成。

目标：

- 初始化 Git 仓库。
- 建立 Python-first 项目结构。
- 写入产品设计、实施计划、当前进度和后续计划文档。
- 创建最小计算测试，验证测试链路可用。

## 阶段 1：数据模型与迁移

目标：

- 使用 PostgreSQL 作为正式本地数据库。
- 建立 SQLAlchemy 模型。
- 建立 Alembic 迁移。
- 覆盖核心表：
  - fund_basic
  - fund_nav_daily
  - experiment_group
  - portfolio_experiment
  - portfolio_position
  - stress_period
  - backtest_result
  - backtest_nav_daily

## 阶段 2：CSV 净值导入

目标：

- 先支持手动 CSV 导入。
- 校验基金代码、日期、单位净值、累计净值、复权净值和数据来源。
- 为后续 AKShare 导入保留统一接口。

## 阶段 3：核心回测引擎

目标：

- 实现净值口径选择。
- 实现共同区间对齐。
- 实现缺失净值诊断。
- 实现不再平衡、月度再平衡、季度再平衡。
- 实现总调仓幅度、单边换手率和估算交易成本。
- 实现数据质量 A/B/C/D 分级。

## 阶段 4：实验组与报告

目标：

- 支持主实验、基准实验、变体实验。
- 支持压力区间诊断。
- 生成 Markdown 研究报告。
- 报告中展示净值口径、缺失数据、数据质量和防守资产诊断。

## 阶段 5：本地 Web UI

目标：

- 基金池页面。
- 实验组列表。
- 创建组合实验页面。
- 回测看板。
- 防守资产诊断和报告页面。
